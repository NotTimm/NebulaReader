## New: scroll a zoomed page with the mouse

On a laptop you can pinch to zoom in on a comic page and then scroll down it with two fingers. With a desktop mouse, the wheel zooms, and the only way to move down a zoomed page was to click and drag. Now you can scroll with the mouse too:

- Zoom in with the wheel as usual, then **hold Ctrl (Cmd on a Mac) and turn the wheel** to move down and back up the page. Each notch moves a steady step, and the page stops at its edges.
- Hold **Ctrl + Shift** (Cmd + Shift on a Mac) to move sideways, which helps with wide two-page spreads.
- The zoom stays exactly where you left it while you scroll.
- On a page that isn't zoomed in, Ctrl + wheel does nothing: the whole page is already on screen. (It used to start zooming, which the plain wheel already does.)
- Touchpads work as before. Ctrl + two-finger scroll and pinching still zoom, including on Windows, which reports a touchpad pinch as Ctrl + wheel. Only a real mouse wheel scrolls.
- On a Mac it's Cmd rather than Ctrl, because macOS uses Ctrl + scroll for its own screen zoom when that accessibility setting is on.

The zoom button's tooltip and the tips on the reader's start screen mention the new shortcut.

## Updating

Windows and Mac: Nebula offers the update itself (from 0.1.7 on). Fedora (COPR): `sudo dnf upgrade nebula-reader`. Everything else: download the package for your system below.

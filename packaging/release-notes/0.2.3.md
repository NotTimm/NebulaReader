Right-to-left manga reading, aligned two-page spreads, CB7 and CBT archives, layered frosted glass cards, faster big libraries, and under-the-hood security and stability fixes.

## Manga & comic reading

- **Right-to-left (manga) mode (`R`).** Toggle RTL from the reader's header bar or press **`R`** to flip `←` / `→` page turning and place the next page on the left in two-page spreads. Your choice is **remembered per series**, so manga stays right-to-left while Western comics stay left-to-right; **Settings → Reading** sets the default for everything else.
- **Cover page alone in two-page mode.** Enabled by default in **Settings → Reading**, each chapter's cover page stands alone so two-page spreads line up properly instead of pairing off by one. Two-page mode also never pairs across chapter boundaries, and stepping backwards always mirrors stepping forwards around solo covers and wide spreads.
- **CB7 and CBT archives.** Local `.cb7` (7z) and `.cbt` (tar) comic archives now scan into your library, show up in the file picker, and register under *Open With* on Linux and Windows alongside `.cbz` and `.cbr`.

## Layered frosted glass

- **Wikipedia and Fandom cards** (main-page boxes, infoboxes, figure frames, and Fandom wiki cards) now render as translucent layered glass panes with soft borders and theme-matched corners whenever frosted windows (COSMIC) or **Mica / Acrylic** (Windows 11) are active, instead of opaque slabs.
- **Windows 11 Mica / Acrylic:** OPDS catalog cards and banners now layer as translucent glass over the backdrop too. Solid themes and non-frosted desktops are unchanged.

## Faster libraries & easier bug reports

- **Big libraries stay smooth.** Library reloads and cover thumbnail checks now run off the UI thread against SQLite WAL (dropping stale search results as you type), and sorted shelf sections are cached instead of being re-sorted on every redraw.
- **Copy diagnostic info.** **Settings → About** now has a one-click **Copy diagnostic info** button that copies your app version, OS, desktop/look, graphics environment, and source counts (with no tokens, URLs, or file paths) to make bug reports much easier.

## Security & stability fixes

- **Windows URL handling & updater:** External links now open directly via `ShellExecuteW` instead of `cmd /C start` (so URLs with `&` query parameters work properly and untrusted links in EPUBs or OPDS feeds can't invoke shell commands), external book links are restricted to `http://`, `https://`, and `mailto:`, and the Windows in-app updater passes paths via environment variables so `&`, `%`, or `^` in folder names never break updates.
- **Malformed & truncated archives:** ZIP, EPUB, and RAR readers cap entry preallocation and decompressed sizes, and remote CBZ/CBR range readers bounds-check offsets and short HTTP responses instead of panicking.
- **Atomic config & credential saves:** Settings, Jellyfin accounts, OPDS accounts, and the ComicVine API key now write atomically via a temporary file (created mode `0600` on Unix before bytes are written).

## Packaging & builds

- Faster release and Fedora COPR builds using parallel ThinLTO and parallel codegen.
- Added starter packaging files for **Homebrew Cask** (`packaging/homebrew/`) and **Arch Linux AUR** (`packaging/aur/`).

## Installing

Windows and Mac: Nebula offers the update itself. Fedora: `sudo dnf upgrade nebula-reader` once the COPR build is done (or `sudo dnf copr enable timbo-slice/nebula-reader` and `sudo dnf install nebula-reader` the first time). Everything else: download the package for your system below.

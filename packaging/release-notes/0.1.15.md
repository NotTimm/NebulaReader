## Changed: CBR comics get a page index instead of a conversion

**Convert to CBZ is gone.** It rewrote your CBR files as CBZs next to the originals and moved the CBRs to the Trash, which meant Nebula needed permission to change files in your home folder. CBRs from Jellyfin don't need converting any more: Nebula reads them page by page from a page index, and leaves your files exactly as they are. Files you converted before stay as they are.

- **The first time you open a Jellyfin CBR, the loading screen says "Creating index of CBR comic…"** while Nebula works out where each page sits in the file. The index is kept, so the next time that comic opens straight away.
- **Building indexes ahead of time** (right-click a Jellyfin series or chapter, then Build Page Index) now says "Creating index of CBR comic…" for one, or "Creating indexes of CBR comics… 2 of 5" for several.
- Local CBR files open as before: pages are unpacked as you reach them.

## Under the hood

- Brought up to date with the latest COSMIC toolkit (libcosmic) from System76.
- Updated the libraries Nebula is built on, including security fixes in the XML reader used for EPUB books and ComicInfo files (quick-xml) and in the HTTP/2 code used for Jellyfin and metadata lookups (h2).
- Nebula no longer needs a Trash library, so the download is a little smaller.

## Updating

Windows and Mac: Nebula offers the update itself (from 0.1.7 on). Fedora (COPR): `sudo dnf upgrade nebula-reader`. Everything else: download the package for your system below.

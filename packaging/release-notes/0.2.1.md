A small update to 0.2.0 for OPDS catalogs.

## Fixed

- **Adding a catalog by one of its inner pages adds the whole catalog.** Pasting an address from inside a catalog, such as Project Gutenberg's search results (`https://www.gutenberg.org/ebooks/search.opds/`), added just that page: a catalog called "All Books" with a plain list of books and no Popular, Latest or Random. Catalogs name their start page, so Nebula now adds the catalog from there, under its real name ("Project Gutenberg"), whichever of its pages you paste. Already added one that way? Remove it in **Settings → OPDS** and add it again.
- **OPDS is in the library's source menu as soon as you add a catalog.** Before, it only showed up once something had been downloaded from one, so a new catalog's card (its search box and sections like Popular and Latest) couldn't be reached from the menu. Picking **OPDS** now shows your catalogs' cards even when nothing's downloaded yet.

## Installing

Windows installer, Windows zip and Mac app: Nebula offers this update itself (**Update now**). Fedora: `sudo dnf upgrade nebula-reader` from the COPR once it has built. Other systems: download the package for your system below.

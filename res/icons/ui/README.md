# UI icons

Small icons used inside the app (embedded at build time).

- `all.svg`, `local.svg`, `chevron-down.svg`, `check.svg`: drawn for Nebula Reader,
  GPL-3.0 like the rest of the project. Single-colour; the app recolours
  them to the theme's text colour.
- `jellyfin.svg`: the Jellyfin logo, from
  [jellyfin/jellyfin-ux](https://github.com/jellyfin/jellyfin-ux)
  (`branding/SVG/icon-transparent.svg`), © the Jellyfin contributors,
  licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
  Modified: the colour gradient is replaced by a single colour and the
  empty margin is cropped, so it's
  drawn in the theme's text colour like the other icons. This file stays
  under CC BY-SA 4.0. Used to label Jellyfin libraries.

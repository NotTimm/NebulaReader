# Built-in themes

COSMIC theme files (libcosmic's `ThemeBuilder` in RON, the format COSMIC
Settings exports), compiled into Nebula. They're generated by the ignored
test `write_builtin_themes` in `src/themes.rs`: change the palette there and
run `cargo test write_builtin_themes -- --ignored`.

They also import into COSMIC Settings (Appearance → Import).

Colours from:

- COSMIC Dark and Light: libcosmic's defaults (MPL-2.0).
- Catppuccin Mocha and Latte: https://github.com/catppuccin/catppuccin (MIT)
- Nord: https://www.nordtheme.com (MIT)
- Dracula: https://draculatheme.com (MIT)
- Gruvbox: https://github.com/morhetz/gruvbox (MIT)
- Solarized: https://ethanschoonover.com/solarized (MIT)
